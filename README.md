# Reflexion

La animacion fue pensada en demostrar el movimiento de una ballena para nadar, se tiene pensado que solamente se tenga una animacion para adelante, que tenga logica para realizarse que nade arriba y abajo, ya que como se busca un juego parecido a flappy bird pero de una ballena en el oceano, se busca que solamente se mueva para adelante y hacia arriba y abajo.
Por dicha razon la animacion esta generada para solamente recibir inputs hacia las direcciones izquierda, arriba y abajo
